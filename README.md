# COMEDK College Predictor

A web-based college prediction tool that helps COMEDK aspirants explore possible college and branch options using official counselling cutoff data.

## Live Demo

* https://comedkpredictor.netlify.app/

## Features

* Predict colleges based on your COMEDK rank
* Explore opportunities across 150+ engineering colleges
* Browse 60+ engineering branches
* Filter results by preferred colleges and branches
* Search colleges and branches instantly
* View branch-wise closing ranks and cutoff trends
* Mobile-friendly and easy-to-use interface
* Built using official COMEDK counselling data

## Prediction Inputs

* COMEDK Rank
* Preferred College
* Preferred Branch

## Tech Stack

* HTML
* CSS
* JavaScript
* Netlify
* Google Analytics

## Run

* Clone the repository
* Open `index.html` in a modern browser
* Enter your COMEDK rank or percentile
* Select your preferred colleges and branches
* Get personalized college predictions instantly

## Why I Built This

* To help students make informed counselling decisions
* To simplify the process of analyzing cutoff data
* To provide a free and accessible prediction tool
* To build a project that solves a real problem faced by engineering aspirants
* To make COMEDK counselling more transparent and less confusing
